# Évaluation et corrections du cours CSS — 14 octobre 2026

## Note initiale : 7/10

Le cours possédait déjà une bonne couverture : syntaxe, sélecteurs, cascade, unités, modèle de boîte, typographie, couleurs, positionnement, Flexbox, Grid, responsive, médias, formulaires, accessibilité, architecture, animations, container queries, débogage, performance et impression. Les 21 concepts et le projet final donnaient une structure cohérente avec le cours HTML.

### Évaluation initiale

| Critère | Note | Observation |
|---|---:|---|
| Couverture des sujets | 9/10 | Les domaines CSS modernes essentiels étaient présents. |
| Progression pédagogique | 7/10 | Bonne progression générale, mais seulement deux sections dans la plupart des concepts. |
| Exactitude technique | 7/10 | Quelques formulations étaient trop vagues ; une explication du fallback de `var()` pouvait induire en erreur. |
| Exemples et mise en pratique | 7/10 | Exemples utiles et exercices par concept, mais peu d’étapes de diagnostic explicites. |
| Références | 5/10 | Cinq liens seulement pour un cours présenté comme approfondi. |
| Accessibilité et compatibilité | 7/10 | Les thèmes étaient présents, mais certaines règles globales de réduction du mouvement étaient trop agressives. |

## Corrections apportées

- Ajout d’une troisième section ciblée à chacun des 20 modules avancés, portant le cours à **63 sections pédagogiques**.
- Ajout d’explications et d’exemples sur les erreurs courantes, les valeurs calculées, les contextes d’empilement, les tailles intrinsèques, les choix Flexbox/Grid, le contenu long et le diagnostic avec DevTools.
- Correction de la description du fallback de `var()` : le fallback ne remplace pas une variable définie dont la valeur est incompatible avec la propriété consommatrice.
- Précision des règles de cascade en couches, de la spécificité des pseudo-classes fonctionnelles et de l’usage des plages de `font-weight` pour les polices variables.
- Suppression des exemples de réduction du mouvement qui désactivaient globalement toutes les animations et transitions avec `!important`. Les exemples ciblent maintenant les animations décoratives identifiées.
- Correction d’un exemple qui présentait `aria-hidden` comme s’il s’agissait d’une propriété CSS.
- Extension de la bibliographie à **14 références** : documentation MDN, spécifications W3C, ressources WAI et cours web.dev.
- Ajout d’assertions de non-régression pour le nombre de concepts, les sections, les exemples, les références et un point technique corrigé.
- Mise à jour du README et du journal afin de ne pas présenter des tests antérieurs comme une validation de cette nouvelle version.

## État après correction : 8,5/10

Le cours est désormais plus solide sur le plan de la couverture, de la précision technique et de l’apprentissage par exemples. Il reste des améliorations possibles : proposer des corrigés guidés pour les exercices, ajouter quelques mini-évaluations avec explications, puis tester les extraits dans un navigateur réel pour les fonctionnalités modernes et les préférences système.
