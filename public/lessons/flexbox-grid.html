2. Frontend

Mise en page CSS avec Flexbox et Grid

Choisir entre une disposition unidimensionnelle et une grille bidimensionnelle pour construire des interfaces responsive.

Tutoriel détailléLot 6 · 2026

Objectifs d’apprentissage

  • Choisir Flexbox pour aligner des éléments selon un axe.
  • Choisir Grid pour organiser lignes et colonnes.
  • Utiliser gap, flex-wrap, fr, minmax et auto-fit.
  • Construire des mises en page adaptables sans positions fragiles.
  • Tester les débordements et les contenus de longueur variable.

1. Flexbox : organiser un axe

Flexbox est conçu pour distribuer et aligner des éléments le long d’un axe principal. La propriété display: flex active le modèle ; justify-content règle la distribution sur l’axe principal et align-items l’alignement sur l’axe transversal.

.barre {
      display: flex;
      align-items: center;
      justify-content: space-between;
      gap: 1rem;
      flex-wrap: wrap;
    }

flex-wrap: wrap autorise les éléments à passer sur plusieurs lignes lorsque l’espace manque. Le modèle flex peut aussi réduire les éléments ; si un enfant déborde à cause de son contenu, min-width: 0 sur l’enfant peut être nécessaire pour autoriser sa réduction.

2. Grid : lignes et colonnes

CSS Grid permet de définir des colonnes et des lignes coordonnées. Il est particulièrement adapté aux grilles de cartes, aux tableaux de bord et aux structures de page à deux dimensions.

.grille {
      display: grid;
      grid-template-columns: repeat(3, minmax(0, 1fr));
      gap: 1rem;
    }

Les fractions fr répartissent l’espace disponible. minmax(0, 1fr) évite que la taille minimale automatique du contenu impose parfois une colonne trop large. Une grille explicite de trois colonnes ne convient pas à toutes les largeurs : adapte-la au contenu ou utilise une règle auto-adaptative.

3. Grilles responsives

.grille-produits {
      display: grid;
      grid-template-columns: repeat(auto-fit, minmax(min(100%, 15rem), 1fr));
      gap: 1rem;
    }

Cette approche permet au nombre de colonnes de s’ajuster à l’espace disponible. Avec auto-fit, les pistes répétées vides sont repliées quand il reste moins d’éléments que de pistes possibles ; auto-fill conserve ces pistes vides, ce qui peut laisser de l’espace réservé. Une media query reste utile lorsque le design doit réellement changer de comportement à un seuil donné. Choisis les seuils en fonction du moment où le contenu ne tient plus, pas en fonction d’une liste fixe de modèles d’appareils.

4. Placer et aligner

Dans Flexbox, l’ordre visuel peut diverger de l’ordre du DOM si tu utilises order ou des directions inversées. Cela peut surprendre la navigation clavier et les technologies d’assistance. Garde autant que possible un ordre source logique.

Dans Grid, les lignes nommées et les zones nommées peuvent clarifier une mise en page complexe. N’utilise pas Grid pour tout par principe : pour aligner une simple rangée de boutons, Flexbox est souvent plus direct.

5. Déboguer les layouts

Les outils de développement affichent les lignes de grille, les axes Flexbox et les tailles calculées. Si un composant déborde, inspecte d’abord sa largeur minimale, les longues chaînes, les images et les marges. Préfère max-width: 100% pour les médias qui doivent rester dans leur conteneur et évite de masquer globalement le débordement pour cacher un défaut de layout.

Teste avec du texte long, une police agrandie, une fenêtre étroite et un zoom élevé. Une disposition robuste doit s’adapter au contenu réel, pas seulement à la capture d’écran de référence.

Erreurs fréquentes

  • Utiliser Flexbox pour une mise en page complexe à deux dimensions sans raison.
  • Définir un nombre fixe de colonnes sans prévoir les petits écrans.
  • Employer order pour corriger un ordre HTML mal conçu.
  • Masquer le débordement sans en identifier la cause.
  • Oublier les chaînes longues, images larges et contenus traduits.

Analyse approfondie : éviter les débordements de contenu

Flexbox et Grid distribuent l’espace disponible, mais le contenu possède aussi des tailles minimales intrinsèques. Un mot très long, une URL, une image trop large ou un élément avec une largeur fixe peut forcer un débordement malgré une grille qui semble flexible.

Grille robuste pour des cartes

.cartes {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
  gap: 1rem;
}
.carte { min-width: 0; }
.carte img { max-width: 100%; height: auto; }
.carte__titre { overflow-wrap: anywhere; }

auto-fit adapte le nombre de pistes qui peuvent tenir ; minmax() borne leur taille et min-width: 0 autorise un élément de grille à rétrécir sous sa taille minimale automatique. overflow-wrap est utile pour les chaînes qui n’ont pas de points de coupure naturels, mais ne doit pas remplacer une conception de contenu raisonnable.

Choisir le modèle

  • Flexbox convient aux barres d’actions, aux groupes de contrôles et aux alignements principalement sur un axe.
  • Grid convient aux régions où lignes et colonnes doivent se coordonner, comme une galerie ou un tableau de bord.
  • Ne réordonne pas visuellement les éléments d’une manière qui contredit l’ordre de lecture et de focus du DOM.

Teste avec un titre deux fois plus long, une carte supplémentaire et une fenêtre étroite. Une mise en page robuste supporte la variation du contenu, pas seulement les textes de démonstration.

Exercice guidé

Construis une barre d’actions avec Flexbox et une grille de cartes avec Grid. Fais varier la largeur de la fenêtre, allonge les titres et ajoute une carte supplémentaire. Utilise les outils du navigateur pour observer les axes, les colonnes et les causes d’un éventuel débordement.

Critères de réussite

  • Flexbox est utilisé pour aligner la barre d’actions.
  • Grid organise les cartes avec une largeur minimale raisonnable.
  • La mise en page s’adapte à plusieurs largeurs sans débordement involontaire.
  • L’ordre DOM reste logique pour la navigation au clavier.
  • Les textes longs et médias restent dans leur conteneur.
